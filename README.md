# 闲鱼卖家工作台（xianyu-seller-workbench）

**一个本地运行的闲鱼卖家一体化工作台**：AI 客服自动回复 + 进销存记账，一个入口全管。

轻量是最大特点：Python 单进程 + 本地 SQLite + PocketBase 单文件——
**不需要 Docker / MySQL / Redis**，Windows 上解压即用。

> 适合人群：个人/小团队闲鱼卖家，尤其是数码、二手、手作这类咨询量大、
> 又要手动记账的品类。

## 功能

**闲鱼客服（assistant/）**
- 多店铺：每店独立登录态、独立面板、独立数据，互不干扰
- AI 自动回复：本地知识库（Markdown）检索 + 大模型生成草稿，语气按你的店规来
- 硬规则兜底：议价 / 退款 / 纠纷 / 索赔一律不自行表态，回「这个我确认下」并转人工
- 转人工微信推送：PushPlus / Server酱，附买家原话
- 网页面板：会话列表、人工接管、一键切换自动/人工、扫码登录
- 买家图片识别（可选配视觉模型）
- 掉线自愈：定时检测，掉线自动过验证/回填登录态

**进销存（jxc/）**
- 商品 / 进货 / 出货 / 拆机 / 库存调整 / 寄改工单，全套单据
- 「一个框」AI 开单：一句话丢进去，自动解析成单据草稿（DeepSeek）
- 报表 + 每日自动备份 + 手机网页/安卓壳
- 数据全在 `jxc/pb_data` 一个目录，拷走即备份

**工作台（workbench/）**
- 一键启动/停止/重启全部服务，带状态检查
- 统一面板：进销存 + 闲鱼客服双页签 + 各服务实时状态灯
- 订单金额看板：顶部实时显示「待发货 / 已发货待到账」金额合计，
  直连闲鱼卖家工作台接口取数（无需浏览器插件）；
  刷新节奏自选——手动（点按钮随时刷）/ 10 分钟 / 1 小时 / 3 小时 / 5 小时，选择会记住

## 架构

```
┌────────────────────── 卖家工作台 (workbench) ──────────────────────┐
│  统一面板 http://127.0.0.1:8090/workbench/                         │
│  ├─ [进销存] PocketBase :8090 ── AI开单 :8091 (Node 单文件)        │
│  └─ [闲鱼客服] 每店一个 Python 进程（面板 :8767 起）──────────┐    │
│                                                                │    │
│  闲鱼客服流水线：                                               │    │
│  闲鱼消息(WS) → 知识库检索(kb.py) → 大模型草稿 → 发/转人工 ─────┘    │
└────────────────────────────────────────────────────────────────────┘
```

## 快速开始（Windows 10/11）

1. **装依赖**：双击 `setup\安装依赖.bat`
   （自动建 venv、装 Python 依赖、下载 PocketBase；需要网络）
2. **首次配置**：双击 `setup\首次配置.bat`
   （填店名 / DeepSeek Key / 进销存账号；自动建好所有配置）
3. **启动**：双击 `workbench\工作台.bat` → 选 `1` 启动全部服务
4. **使用**：
   - 工作台主页 `http://127.0.0.1:8090/workbench/`
   - 「闲鱼客服」页签里点扫码登录，用**闲鱼小号**扫码
   - 「进销存」页签里开始记账

前置要求：Python 3.10+（必需）、Node.js（用「AI 开单」才需要）、Chrome/Edge（自愈功能用）。

## 目录结构

```
assistant/     闲鱼客服主程序（Python）
  kb.py          本地知识库引擎（检索 + LLM 草稿）
  main.py        主进程：收消息 → 大脑 → 回复/转人工
  panel.py       网页面板后端（含 /status 健康接口）
  shops/         每店一个目录（配置/登录态/数据）
jxc/           进销存（PocketBase + 前端 + AI 开单）
  pb_public/     web 界面（含 workbench 统一面板页）
  ai/            「一个框」AI 解析服务（Node）
workbench/     统一启动器（一键全起全停）
setup/         安装 / 首次配置 / 敏感信息扫描
docs/          知识库写法、常见问题、服务端部署
```
