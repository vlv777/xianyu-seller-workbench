# 知识库写法（决定 AI 客服答得准不准）

知识库是一个 Markdown 文件（默认 `assistant/知识库.md`），AI 只依据它回答，
检索不到的会回「这个我确认下」转人工——所以**把常见问题写全**就是质量的关键。

## 基本结构

用标题分节，标题层级 = 检索路径：

```markdown
# 我的小店 知识库        ← 一级标题是知识库名字

## 店铺基本信息           ← 这几节是「常驻」检索的，必写
- 发货地：xxx
- 默认快递：xxx（包邮）
- 发货时效：拍下后 xx 小时内发出

## 售后政策
- 7 天无理由……

## 注意事项
- ……

## 回复话术模板
### 发货时间
- 买家问：什么时候发货？
- 回复：拍下后 48 小时内发出，发出去给你单号哈。
```

建议必写的四个常驻小节：**店铺基本信息 / 售后政策 / 注意事项 / 回复话术模板**。

## 写法要点

1. **一条一问一答最稳**：`### 标题` 下写「买家问 / 回复」，AI 会照着改口吻
2. **数字要写死**：运费、时效、加价，知识库里没有 AI 绝不乱编
3. **敏感/拿不准的**：在 `assistant/软件配置.json` 的 `custom_rules` 里写店规
   （议价、退款、纠纷类默认一律转人工，不用写也有基础规则）
4. 改完知识库**不用重启**：助手会自动检测文件变化重建索引
5. 面板「设置」里可以改知识库路径（默认同目录 `知识库.md`）

## 补充知识（自动积累）

- 面板里人工确认过的问答可以追加到 `补充知识.md`，它和主知识库一起被检索
- 也可以在 `kb.py --build` 里看到切片结果，调试命中：
  `python assistant/kb.py --retrieve --ask "发货要多久"`
