# 常见问题

## 服务相关

**Q：双击工作台没反应 / 提示缺东西？**
先跑 `setup\安装依赖.bat`（建虚拟环境、装依赖、下载 PocketBase）。
工作台菜单选 3 可随时看各服务端口状态。

**Q：闲鱼助手显示「登录失效」？**
登录态会过期，正常。三种处理顺序：
1. 等 30 分钟自动重试（有时网络抖动引起的会自愈）
2. 面板上点「扫码登录」用闲鱼小号重新扫码
3. 跑一次自愈：`assistant\heal.cmd`（会拉起浏览器取回登录态，可能需要你在弹窗里过一下滑块验证）

**Q：能不能挂多个闲鱼店？**
能。`assistant\店铺管理.cmd` → 4 新建店铺 → 2 启动 → 5 打开某店面板扫码。
每店独立配置/登录态/端口，互不影响。

**Q：AI 回复的口气不像我？**
改知识库 `回复话术模板` 小节；店规（比如不承诺到货时间）写进
`assistant\软件配置.json` 的 `custom_rules`。

**Q：议价、退款这些它会自己回吗？**
不会。默认硬规则：议价/退款/纠纷/索赔一律不自行表态，回「这个我确认下」
并在面板标记「待人工」，配了 PushPlus 会推微信。

## 进销存相关

**Q：网页/手机登录账号是什么？**
首次配置时自己设的邮箱密码。忘了就去 `http://127.0.0.1:8090/_/` 用超级管理员账号重置。

**Q：「AI 开单」不工作？**
它依赖 Node.js 和 DeepSeek key：
- 装 Node（nodejs.org）
- key 写在 `jxc\ai\ai-config.json` 的 `llm_key`，或环境变量 `DEEPSEEK_API_KEY`

**Q：数据在哪？怎么备份？**
全部在 `jxc\pb_data` 一个目录里，拷贝走就是完整备份。

## 其他

**Q：手机能用吗？**
能。手机和电脑同一局域网时浏览器访问 `http://电脑IP:8090`；
或编译 `jxc\android\` 里的安卓壳（改好服务器地址再打包）。

**Q：端口冲突？**
默认进销存 8090、AI 开单 8091、闲鱼面板 8767 起。改闲鱼端口在店铺
`config.json` 的 `port`；进销存端口改 `workbench.ps1` 顶部的 `$PB_PORT`。
